    \section{Introduction}

        This document is Worralop Srichainont's personal \LaTeX\ template for university assignment reports.
        The source is published in the \href{https://github.com/reisenx/LATEX-TEMPLATE}{GitHub repository}.
        It supports a cover page with course and submission details, a running header/footer, a table of contents,
        a small set of callout boxes, clean figures and tables, and syntax-highlighted code snippets via \texttt{minted}.
        It also fully supports ภาษาไทย (Thai language) using the THSarabunPSK font.
        You are free to use and modify this template without any restrictions.

        \begin{notebox}[Note: file layout]
            The template is split into three files: \texttt{preamble.tex} (packages and styling you rarely touch),
            \texttt{metadata.tex} (the fields you edit for every new assignment: title, course, instructor, student ID,
            due date), and \texttt{template.tex} (the actual content, this file). For lecture summaries, use the
            sibling \texttt{lecture\_note/} folder instead, which has its own independent cover and styling.
        \end{notebox}

        \vspace{1em}

        Before compiling this document, install the Pygments library required by the \texttt{minted} package:
        \begin{codeblock}{bash}{}
            pip install Pygments
        \end{codeblock}

        For your \LaTeX\ editor, \href{https://www.overleaf.com/}{\textbf{Overleaf}} is the easiest online option.
        If you prefer to work locally, install \LaTeX\ via \href{https://miktex.org/download}{\textbf{MikTeX}}
        and use an editor such as \href{https://code.visualstudio.com/}{\textbf{Visual Studio Code}} (with the LaTeX Workshop
        extension) or \href{https://www.xm1math.net/texmaker/}{\textbf{TeXMaker}}.

        To compile, select \textbf{XeLaTeX} as the compiler, or run:
        \begin{codeblock}{bash}{}
            xelatex -shell-escape -interaction=nonstopmode template.tex
        \end{codeblock}

    \section{Callout Boxes}

        A small, muted set of callout boxes is available for flagging important content without cluttering the page.

        \begin{defbox}
            A \textbf{callout box} is a visually distinct block used to draw attention to a specific piece of content,
            such as a definition, a worked example, or a warning, separate from the surrounding body text.
        \end{defbox}

        \begin{examplebox}
            \texttt{\textbackslash begin\{examplebox\}} renders this box. Pass an optional argument to change the
            title, e.g. \texttt{\textbackslash begin\{examplebox\}[Example: recursion]}.
        \end{examplebox}

        \begin{takeawaybox}
            Use callout boxes sparingly. Reserve them for content you would circle in a printed handout, not for
            every paragraph, so they keep their emphasis.
        \end{takeawaybox}

    \section{Lists}

        \texttt{enumitem} controls list spacing globally, keeping lists airy but still compact enough to scan.

        \begin{enumerate}
            \item First step of a procedure.
            \item Second step, with a nested list:
                \begin{itemize}
                    \item Supporting detail one.
                    \item Supporting detail two.
                \end{itemize}
            \item Final step.
        \end{enumerate}
